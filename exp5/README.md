## Objective
To implement a Decision Tree classifier, extend it to a Random Forest ensemble, tune hyperparameters, and compare both models.

## Datasets
- Wisconsin Diagnostic Breast Cancer (WDBC) Dataset: 569 rows, 30 features, binary classification.

## Models Evaluated
1. Decision Tree
2. Random Forest

## Methodological Workflow
- Load WDBC dataset and perform basic preprocessing.
- Train Decision Tree and Random Forest classifiers.
- Hyperparameter tuning using 5-Fold Cross-Validation.
- Compare models using standard classification metrics.

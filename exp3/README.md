## Objective
To implement Linear, Ridge, Lasso, and Elastic Net regression to predict a continuous target (sanctioned loan amount) and compare models considering the bias-variance tradeoff.

## Datasets
- HackerEarth Loan Sanction Amount Dataset: 30,000 rows, 24 columns, continuous target.

## Models Evaluated
1. Linear Regression
2. Ridge Regression
3. Lasso Regression
4. Elastic Net

## Methodological Workflow
- Load and preprocess loan dataset.
- Exploratory Data Analysis (EDA).
- Train regression models.
- Evaluate using R2, MSE, and MAE.
- Analyze the effect of regularization strength and evaluate under/over-fitting.

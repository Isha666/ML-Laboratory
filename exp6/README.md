## Objective
To understand and implement Bagging, Boosting, and Stacking ensemble strategies, build a stacked model using multiple base learners, and compare models in terms of stability, bias, and variance.

## Datasets
- Wisconsin Diagnostic Breast Cancer (WDBC) Dataset: 569 samples, 30 features, binary classification.

## Models Evaluated
1. Bagging Classifier
2. AdaBoost Classifier
3. Gradient Boosting Classifier
4. Stacked Ensemble Model

## Methodological Workflow
- Load dataset and check for missing values.
- Train Bagging and Boosting classifiers.
- Build and train a Stacked Ensemble model.
- Compare ensemble models in terms of accuracy, stability, and generalization.
